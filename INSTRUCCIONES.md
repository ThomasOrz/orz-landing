# 📸 Instrucciones para Agregar tu Foto

## Paso 1: Guardar tu Imagen

1. Descarga o guarda la foto profesional que quieres usar
2. Renómbrala a: **`thomas-profile.jpg`**
3. Arrástrala a esta carpeta:

```
/Users/thomasorz/PROGRAMACION/LANDING/assets/images/
```

## Paso 2: Verificar que se guardó correctamente

Abre la Terminal y ejecuta:

```bash
ls -la /Users/thomasorz/PROGRAMACION/LANDING/assets/images/
```

Deberías ver el archivo `thomas-profile.jpg` en la lista.

## Paso 3: Recargar la Página

1. Abre el archivo `index.html` en tu navegador
2. Presiona `Cmd + R` para recargar
3. Tu foto debería aparecer en el hero section

---

## 🔍 Alternativa Rápida (Finder)

1. Abre **Finder**
2. Presiona `Cmd + Shift + G` (Ir a carpeta)
3. Pega esta ruta: `/Users/thomasorz/PROGRAMACION/LANDING/assets/images/`
4. Arrastra tu foto ahí y renómbrala a `thomas-profile.jpg`

---

## ✅ Formatos Soportados

- `.jpg` o `.jpeg` (recomendado)
- `.png` (también funciona)
- `.webp` (moderna y optimizada)

**Tamaño recomendado:** 800x1000px mínimo para buena calidad

---

Si tienes problemas, dime dónde está guardada tu foto y la copio automáticamente.
